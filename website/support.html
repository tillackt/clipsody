Clipsody-Support – Problem melden oder Idee vorschlagen

Clipsody ist ein kostenloses Open-Source-Projekt. Probleme und Ideen werden öffentlich auf GitHub gesammelt – so sieht jeder, was bekannt ist und woran gearbeitet wird.

Erst kurz prüfen

  • Viele Fragen beantworten die Häufigen Fragen, die Installation erklärt Installation.
  • Ist dein Clipsody aktuell? Menüleisten-Symbol → Nach Updates suchen …
  • Vielleicht hat es schon jemand gemeldet: bekannte Probleme auf GitHub.

Problem melden oder Idee vorschlagen

Füll aus, was du weißt. Der Button öffnet GitHub mit deinen Angaben; dort kannst du noch ergänzen und absenden. Du brauchst ein kostenloses GitHub-Konto.

Einstellungen → Info → Version

Apple-Menü → Über diesen Mac

Issues sind öffentlich. Bitte keine Passwörter oder andere private Inhalte aus der Zwischenablage angeben. Screenshots helfen – prüf vorher, was darauf zu sehen ist.

Was uns am meisten hilft

  • Die Clipsody-Version (Einstellungen → Info) und deine macOS-Version.
  • Die Schritte, die zum Problem führen – so genau wie möglich.
  • Was du erwartet hast und was stattdessen passiert ist.
  • Bei Problemen beim Einfügen oder mit Bildern: das Protokoll, bei Abstürzen: den Absturzbericht. Wie du beides bekommst, zeigt GitHub im Formular.

Eine Sicherheitslücke gefunden?

Bitte nicht öffentlich melden, sondern über die vertrauliche Meldung auf GitHub – die sieht nur der Entwickler.
