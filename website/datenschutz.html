Support und GitHub

Das Formular auf der Support-Seite sendet nichts an mich. Beim Klick auf einen der Buttons öffnet der Browser das Formular für ein Issue auf GitHub und überträgt dabei die eingegebenen Angaben an GitHub. Abgeschickt wird das Issue erst dort, mit einem eigenen GitHub-Konto. Issues sind öffentlich sichtbar. Für die Verarbeitung durch GitHub gilt die Datenschutzerklärung von GitHub.

Downloads

Clipsody wird über GitHub zum Download angeboten. Beim Download verarbeitet GitHub die dafür technisch notwendigen Daten (z. B. die IP-Adresse) und zählt die Downloads; ich sehe nur die Anzahl, keine Daten über Personen. Rechtsgrundlage und Übermittlung in die USA wie oben bei der Website.

Die App

Clipsody speichert den Zwischenablage-Verlauf ausschließlich lokal auf dem Mac der Nutzerin bzw. des Nutzers. Inhalte der Zwischenablage werden nie übertragen.

Update-Prüfung: Nur wenn die Nutzerin bzw. der Nutzer zustimmt (beim ersten Start abgefragt, Standard: aus) oder selbst „Jetzt suchen“ wählt, ruft die App bei GitHub die Nummer der neuesten Version ab, bei Zustimmung höchstens einmal täglich. Dabei erhält GitHub technisch notwendig die IP-Adresse und die Versionsnummer der App.

Update installieren: Nur wenn die Nutzerin bzw. der Nutzer im Hinweis auf eine neue Version „Installieren und neu starten“ wählt, lädt die App diese Version (Disk-Image und Prüfsumme) von GitHub. Auch dabei erhält GitHub die IP-Adresse. Darüber hinaus nutzt die App kein Netzwerk.

Rechtsgrundlage der automatischen Prüfung ist die Einwilligung (Art. 6 Abs. 1 lit. a DSGVO). Sie lässt sich jederzeit unter Einstellungen → Allgemein widerrufen; die bis dahin erfolgten Abfragen bleiben davon unberührt. Bei der Suche und der Installation per Klick ist Rechtsgrundlage Art. 6 Abs. 1 lit. f DSGVO: das Interesse, die ausdrücklich angefragte Information bzw. Version zu liefern. Zur Übermittlung in die USA siehe oben.
