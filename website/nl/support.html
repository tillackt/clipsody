Clipsody-support – meld een probleem of stel een idee voor

Clipsody is gratis en open source. Problemen en ideeën worden openbaar op GitHub verzameld, zodat iedereen kan zien wat al bekend is en waaraan wordt gewerkt.

Controleer eerst

  • Veel vragen worden beantwoord in de FAQ, de installatie staat bij Installatie.
  • Is je Clipsody up-to-date? Symbool in de menubalk → Zoek naar updates…
  • Misschien heeft iemand het al gemeld: bekende problemen op GitHub.

Meld een probleem of stel een idee voor

Vul in wat je weet. De knop opent GitHub met je gegevens al ingevuld; daar kun je nog details toevoegen en het versturen. Je hebt een gratis GitHub-account nodig.

Instellingen → Info → Versie

Apple-menu → Over deze Mac

Issues zijn openbaar. Zet er geen wachtwoorden of andere privé-inhoud van je klembord in. Screenshots helpen, maar controleer eerst wat erop staat.

Wat ons het meest helpt

  • De Clipsody-versie (Instellingen → Info) en je macOS-versie.
  • De stappen die tot het probleem leiden, zo precies mogelijk.
  • Wat je verwachtte en wat er in plaats daarvan gebeurde.
  • Bij problemen met plakken of afbeeldingen: het logboek; bij crashes: het crashrapport. Hoe je beide krijgt, laat GitHub in het formulier zien.

Een beveiligingsprobleem gevonden?

Meld het alsjeblieft niet openbaar, maar gebruik de vertrouwelijke melding op GitHub – alleen de ontwikkelaar kan die zien.
