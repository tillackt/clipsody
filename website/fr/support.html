Assistance Clipsody – signaler un problème, proposer une idée

Clipsody est un projet open source gratuit. Les problèmes et les idées sont rassemblés publiquement sur GitHub : chacun peut voir ce qui est déjà connu et ce qui est en cours.

À vérifier d’abord

  • Beaucoup de questions trouvent leur réponse dans la FAQ, et l’installation est expliquée sous Installation.
  • Votre Clipsody est-il à jour ? Icône de la barre des menus → Rechercher des mises à jour…
  • Quelqu’un l’a peut-être déjà signalé : problèmes connus sur GitHub.

Signaler un problème ou proposer une idée

Remplissez ce que vous pouvez. Le bouton ouvre GitHub avec vos indications déjà saisies ; vous pourrez y ajouter des détails, puis l’envoyer. Il vous faut un compte GitHub gratuit.

Réglages → Infos → Version

Menu Pomme → À propos de ce Mac

Les tickets sont publics. N’y mettez ni mots de passe ni autre contenu privé du presse-papiers. Les captures d’écran aident, mais vérifiez ce qu’elles montrent.

Ce qui nous aide le plus

  • La version de Clipsody (Réglages → Infos) et votre version de macOS.
  • Les étapes qui mènent au problème, aussi précisément que possible.
  • Ce que vous attendiez et ce qui s’est passé à la place.
  • Pour un problème de collage ou d’image : le journal ; en cas de plantage : le rapport de plantage. Le formulaire GitHub explique comment obtenir les deux.

Vous avez trouvé une faille de sécurité ?

Ne la signalez pas publiquement. Utilisez plutôt le signalement privé sur GitHub ; seul le développeur peut le voir.
