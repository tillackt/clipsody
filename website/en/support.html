Clipsody Support – Report a Problem or Suggest an Idea

Clipsody is a free open-source project. Problems and ideas are collected publicly on GitHub, so everyone can see what is known and what is being worked on.

Check first

  • Many questions are answered in the FAQ, installation in Install.
  • Is your Clipsody up to date? Menu bar icon → Check for Updates…
  • Maybe someone has already reported it: known issues on GitHub.

Report a problem or suggest an idea

Fill in what you can. The button opens GitHub with your entries filled in; there you can add details and send it. You need a free GitHub account.

Settings → Info → Version

Apple menu → About This Mac

Issues are public. Please do not include passwords or other private clipboard contents. Screenshots help, but check what they show.

What helps us most

  • The Clipsody version (Settings → Info) and your macOS version.
  • The steps that lead to the problem, as exactly as possible.
  • What you expected and what happened instead.
  • For paste or image problems: the log; for crashes: the crash report. The GitHub form shows how to get both.

Found a security problem?

Please do not report it publicly. Use the private report on GitHub instead; it is only visible to the developer.
